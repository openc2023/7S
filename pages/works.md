# 作品列表文字

<!-- 中文编辑提示：这是实际文案来源，中文说明不会显示在网页中。 -->

只修改下方 `json text` 代码块中的值，不改字段名和代码块标记。网站文案填写英文。
数组每项是一行标题或一个列表项；{花括号} 是自动替换的占位符，请保留。双引号、逗号和方括号须保持完整。

| 字段 | 页面位置 / 修改说明 |
| --- | --- |
| browserTitle | 浏览器标签标题 |
| eyebrow | 顶部小字 |
| title | 大标题 |
| intro | 开场简介 |
| all | 全部分类显示名，不改变筛选逻辑 |
| search | 搜索框提示 |
| clear | 清空搜索提示 |
| year | 年份选择提示 |
| allYears | 全部年份 |
| sort | 排序选择提示 |
| view | 视图切换名称 |
| twoColumns | 两列提示 |
| threeColumns | 三列提示 |
| list | 列表提示 |
| sortManual | 推荐排序 |
| sortNew | 年份倒序 |
| sortOld | 年份正序 |
| sortAZ | 标题正序 |
| sortZA | 标题倒序 |
| sortRecent | 最近添加排序 |
| noResults | 无结果标题 |
| noMatches | 无结果说明 |
| reset | 重置筛选按钮 |
| filters | 筛选条件前缀 |
| clearAll | 清空筛选按钮 |
| count | 数量提示，保留占位符 |
| signature | 列表底部署名 |
| seriesEyebrow | 作品页下方系列区小字 |
| seriesTitle | 作品页下方系列区大标题 |
| seriesAll | 系列区「全部」按钮 |
| seriesWorks | 系列卡片上的作品数，保留占位符 |
| viewSeries | 系列卡片悬停提示 |
| seriesLabel | 系列页顶部小字 |
| aboutSeries | 系列页简介标题 |
| inThisSeries | 系列页作品区小字 |
| seriesWorksTitle | 系列页作品区大标题 |
| seriesSearch | 系列页搜索框提示 |
| seriesEmpty | 系列页没有作品时 |
| seriesSummary | 系列页底部数量，保留占位符 |
| planned | 占位卡状态 |
| imagePending | 图片占位卡标记 |
| videoPending | 视频占位卡标记 |
| previewPending | 占位卡悬停提示 |
| allWorks | 系列页底部返回全部作品 |
