# 首页文字

<!-- 中文编辑提示：这是实际文案来源，中文说明不会显示在网页中。 -->

只修改下方 `json text` 代码块中的值，不改字段名和代码块标记。网站文案填写英文。
数组每项是一行标题或一个列表项；{花括号} 是自动替换的占位符，请保留。双引号、逗号和方括号须保持完整。

| 字段 | 页面位置 / 修改说明 |
| --- | --- |
| eyebrow | 顶部小字 |
| disciplines | 右上角小字 |
| heroLines | 大标题，每项一行 |
| intro | 标题下方简介 |
| artHint | 动效操作提示 |
| artFoot | 动效下方短句 |
| explore | 查看作品链接 |
| marquee | 滚动文字，按顺序显示 |
| aboutLabel | 关于区编号小字 |
| aboutText | 关于区简介 |
| collaborateLabel | 合作区编号小字 |
| collaborateTitle | 合作区标题 |
| collaborateLink | 合作按钮 |
