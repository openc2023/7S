# 工作室文字

<!-- 中文编辑提示：这是实际文案来源，中文说明不会显示在网页中。 -->

只修改下方 `json text` 代码块中的值，不改字段名和代码块标记。网站文案填写英文。
数组每项是一行标题或一个列表项；{花括号} 是自动替换的占位符，请保留。双引号、逗号和方括号须保持完整。

| 字段 | 页面位置 / 修改说明 |
| --- | --- |
| browserTitle | 浏览器标题 |
| eyebrow | 顶部小字 |
| title | 大标题 |
| intro | 标题下方简介 |
| heroLines | 工作室标语，每项一行 |
| body | 完整介绍段落 |
| projects | 作品统计标题 |
| disciplines | 分类统计标题 |
| years | 作品年份数统计标题 |
| luckyLabel | 自定义数字标题 |
| luckyNumber | 自定义数字，非负整数 |
| servicesLabel | 服务列表标题 |
| services | 服务名称，可增删条目 |
| contactLink | 底部联系按钮 |
