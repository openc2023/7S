# 联系页文字

<!-- 中文编辑提示：这是实际文案来源，中文说明不会显示在网页中。 -->

只修改下方 `json text` 代码块中的值，不改字段名和代码块标记。网站文案填写英文。
数组每项是一行标题或一个列表项；{花括号} 是自动替换的占位符，请保留。双引号、逗号和方括号须保持完整。

| 字段 | 页面位置 / 修改说明 |
| --- | --- |
| browserTitle | 浏览器标题 |
| metaDescription | 搜索引擎描述 |
| eyebrow | 顶部小字 |
| title | 大标题 |
| intro | 开场简介 |
| headingLines | 左侧大字，每项一行 |
| inquiries | 邮箱上方标题 |
| copyEmail | 复制邮箱按钮 |
| emailCopied | 复制成功提示 |
| social | 社交区标题 |
| socialEmpty | 未填写社交链接时提示 |
